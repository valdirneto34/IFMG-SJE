Notícias

Processo Seletivo 2027

IFMG Campus São João Evangelista abre inscrições para Processo Seletivo de 2027. Há vagas para diversos cursos, incluindo o Bacharelado em Sistemas de Informação.

Bolsas de Iniciação Científica

Publicado o edital para bolsas de Iniciação Científica. Projetos focados em métodos multicritério de apoio à decisão (como AHP e TOPSIS) terão linhas de pesquisa dedicadas neste ciclo.

Novo Laboratório de BD

Novo laboratório virtual de Banco de Dados permitirá aos alunos testarem funções, *triggers* e consultas complexas utilizando PostgreSQL e MySQL, com ambientes totalmente conteinerizados via Docker.

Atualização: Moradia Estudantil

Setor de Moradia Estudantil e Assistência Social atualiza diretrizes de alojamento e contratos. Estudantes devem ficar atentos às novas cláusulas de uso e prazos de renovação para o próximo semestre.

Destaques

Semana Acadêmica de Tecnologia

Turma do 6º período apresenta projetos de inovação envolvendo desenvolvimento Full-Stack (Spring Boot e React) durante a Semana Acadêmica de Tecnologia.

Reforma na UAN

IFMG Campus São João Evangelista inicia nova reforma para expansão da UAN e vai passar a oferecer um cardápio especial às terças-feiras para toda a comunidade acadêmica.

Monitoramento com Áudio

Grupo de pesquisa aplicada desenvolve sistema inovador que utiliza extração de características de áudio (como MFCCs) e geração de espectrogramas em Python para monitorar a biodiversidade local por meio dos sons da natureza.

Mostra de Front-end

Mostra de Front-end premia interfaces construídas nas disciplinas de Desenvolvimento Web. Os projetos destacaram o uso avançado de Flexbox, variáveis CSS e acessibilidade, e já estão disponíveis no GitHub e hospedados na Vercel.

Outras Notícias

Gestão de Campanhas

Sistema de Gestão de Campanhas Comerciais e sorteio de cupons, desenvolvido por estudantes do campus, começa a ser testado por lojistas locais para impulsionar as vendas de fim de ano.

Minicurso de Python

Projeto de extensão promove minicurso de introdução à programação e análise de dados utilizando Python e a biblioteca Pandas para alunos do ensino médio.

Mutirão GitHub

IFMG promove mutirão para criação e atualização de portfólios no GitHub, ajudando futuros profissionais de TI a documentarem suas pilhas tecnológicas e projetos full-stack de forma atrativa para o mercado.

Segurança de Redes

Núcleo de Tecnologia da Informação implementa novas políticas de segurança no campus utilizando roteadores sem fio corporativos e *switches* gerenciáveis para otimizar o acesso ao Portal e ao AVA Moodle.
